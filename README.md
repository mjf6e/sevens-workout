# Sevens

A no-equipment HIIT circuit workout app that runs in the browser and installs to a phone home screen.

- 8 preset circuits, including a classic 12-exercise, 30-on, 10-off routine
- Exercise library with 39 movements, form cues, difficulty levels, and low-impact filtering
- Custom workout builder with adjustable work and rest times
- Smart Workout: answer a quick check-in on energy, motivation, time, and focus, and get a circuit built for the day. It adapts to your level based on how you rate each workout.
- Voice prompts, a beeping 5-second countdown, and an optional spoken countdown
- Progress history stored locally in the browser
- Works offline after the first visit

Sevens is an independent project inspired by the 12-exercise HICT circuit described by Brett Klika and Chris Jordan. It is not affiliated with or endorsed by any company. Talk to a doctor before starting a new exercise program.

## Run locally

Open `index.html` in a browser. There is no build step.
